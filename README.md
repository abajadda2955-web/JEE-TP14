# TP14 – Automatisation d'une application Spring Boot avec scripts Bash
---
Description du TP

Ce TP consiste à automatiser le cycle de vie complet d'une application Spring Boot en utilisant des scripts Bash. Au lieu de lancer l'application depuis un IDE (IntelliJ, Eclipse), on utilise des scripts en ligne de commande pour démarrer, arrêter, superviser et déployer l'application.

L'application est une simple API REST qui tourne sur le port 8090 avec une base de données H2 en mémoire. Mais l'important n'est pas l'application elle-même, c'est la façon dont on la gère.

---

Objectifs du TP


--> *Automatisation*	Remplacer les actions manuelles (clic sur "Run" dans l'IDE) par des scripts automatisés

-->*Gestion des processus* 	Apprendre à lancer un processus en arrière-plan, retrouver son PID, et l'arrêter

-->*Redirection des logs*	Capturer la sortie de l'application (logs, erreurs) dans des fichiers

-->*Supervision* 	Vérifier que l'application tourne correctement via des requêtes HTTP

*-->Déploiement* 	Compiler l'application en JAR et la lancer sans Maven

-->*Reproductibilité*  	Pouvoir déployer l'application sur n'importe quel serveur Linux sans IDE
